# Manifesto — El problema que resuelve fs-scaffold

## El problema que estaba harto de tener

Cada vez que arrancaba un proyecto nuevo, perdía días enteros en lo mismo de siempre:

- Decidir qué tecnologías usar
- Configurarlas para que se hablen entre sí
- Montar reglas de calidad
- Dejar la documentación lista
- Decidir cómo iba a colaborar con las distintas IAs que uso a la vez

Y al final, cada proyecto salía diferente. Lo que aprendía en uno, se me olvidaba en el siguiente.

Encima, cuando algo se rompía a la mitad, no había forma de saber por qué. Y si dos sesiones de trabajo se pisaban, mal asunto.

## La respuesta

**fs-scaffold es la respuesta a todo eso.**

Una sola herramienta que:
- Monta el proyecto **siempre igual**
- Con **todo lo bueno** desde el primer minuto
- Y es capaz de **recuperarse** si algo se tuerce
