# Qué deja montado en el proyecto

Todo lo que normalmente tendrías que configurar a mano. Y todo igual entre proyectos: cero variación.

---

## Checklist de entregables

### Instrucciones únicas para todas las IAs colaboradoras
Un solo sitio donde están las reglas del proyecto. Da igual la herramienta de IA que uses después: todas reciben las mismas instrucciones.

---

### Reglas de calidad que se aplican solas
Cada vez que guardas un cambio, el proyecto comprueba que cumple las reglas. Si no las cumple, no te deja seguir hasta arreglarlo.

---

### Avisos de seguridad antes de subir
Si alguien intenta subir contraseñas o datos sensibles por error, el proyecto los detecta y bloquea el envío.

---

### Plantillas para escribir bien las funcionalidades nuevas
Cuando se te ocurre algo nuevo, no empiezas de cero: rellenas una plantilla que ya te obliga a pensar en todos los casos.

---

### Catálogo de skills auxiliares verificadas
Herramientas extra listas para usar:
- Auditar el código
- Redactar mensajes
- Escribir tests
- Generar documentación

Todas con sello de origen verificado.

---

### Documentación viva del proyecto
La parte del proyecto que cambia rara vez queda como referencia clara. Y se actualiza sola cuando algo importante cambia.
